A deterministic Node 22 program that draws one 1024×1024 image summing up the world news of Thursday 26 November 2026: a hero on the Houthi claim of a strike on Saudi Arabia's Ras Tanura refinery (Brent $94.61, +3.5%) plus four cards — Trump's new tariffs on 14 partners (China 20%, rising to 40%), the Nasdaq AI rout (−4.2% intraday, close −0.6%), Shenzhou-24 carrying the first Pakistani astronaut to Tiangong, and the Cairo tanker fire (31 killed). No network, no randomness, no external files: the PNG encoder and a 5×7 bitmap font are hand-rolled in the program itself, so two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
